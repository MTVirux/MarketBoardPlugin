# MarketTerror
Market board information plugin for XIVLauncher / Dalamud

# THIS IS NOT THE ORIGINAL PLUGIN. THIS VERSION WAS MODDED BY MTVIRUX

## Usage

Open the window with `/pmb`, `/mt` or `/marketterror`, or from the plugin installer.

Add `buylist` (or `shoppinglist`) to any of those commands to toggle the buy list window, e.g. `/mt buylist`.

## Features

- Click on market board listings to automatically execute `/li <world> mb` command (Requires [Lifestream](https://github.com/NightmareXIV/Lifestream?tab=readme-ov-file#installation))
    - Quickly teleport to the world where items are listed
    - Toggle the feature on/off in plugin settings
